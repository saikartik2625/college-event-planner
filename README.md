# Basee — AI College Event Planner

## Run locally

1. Paste your MongoDB Atlas URI into the root `.env` file as `MONGODB_URI`.
2. In Atlas → Network Access, allow your current IP.
3. Install and start:

```bash
cd /Users/manishsrinivasmovva/Desktop/Basee
npm run install-all
npm run dev
```

- Backend: http://localhost:5001
- Frontend: URL printed by Vite (usually http://localhost:5173)

Sign up once as **Admin** to create events, then as **Student** to register.
